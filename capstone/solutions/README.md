# TaskFlow Reference Solutions

This directory contains reference solutions for each milestone for validation, testing, and grading.

- **m1-m2**: Base express server with health check and graceful shutdown
- **m3-m5**: MongoDB schema, REST CRUD routes, validation and error pipeline
- **m6-m7**: React frontend with data fetching and optimistic state updates
- **m8**: Authentication with bcrypt hashing and JWT verification middleware
- **m9**: WebSockets server with Socket.IO room broadcast
- **m10**: Production Dockerfile and GitHub Actions CI workflow

## Test Solutions
Run the validation script to verify that reference implementations satisfy all acceptance criteria:
```bash
node capstone/solutions/verify.mjs
```
