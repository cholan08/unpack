# TaskFlow — Capstone Project Starter

TaskFlow is the capstone project for **Unpacked: MERN Full Stack**.
You will build a full-stack real-time collaborative task board from scratch across 10 milestones:

1. **Skeleton**: Monorepo scripts and tooling
2. **Server**: Express server with `/healthz`
3. **Database**: MongoDB connection with Mongoose `Task` model
4. **CRUD**: REST endpoints (`GET`, `POST`, `PATCH`, `DELETE`)
5. **Validation**: Edge schema validation and centralized error handling
6. **Frontend**: React + Vite application with data fetching
7. **UI**: Form states, optimistic UI updates, and error rollbacks
8. **Auth**: User registration, password hashing (`bcrypt`), and JWT protection
9. **Realtime**: WebSockets (`socket.io`) for live multi-user board updates
10. **Deploy & Defend**: Cloud deployment, automated CI, and architectural defense

## Quick Start
```bash
# Install dependencies
npm install

# Start development servers
npm run dev
```
